Downloads

How Coldarr treats qBittorrent's downloads on your downloads tiers. A finished download sits on the download drive for the settle time, then moves to seed storage and gets the seed label. Downloads still in progress are never moved, and neither is anything without a label set to move.

The category a download gets once it has landed on seed storage - only then, so a move that fails never leaves a download labeled as moved. Coldarr creates it in qBittorrent if it's missing.

qBittorrent keeps a download with Automatic Torrent Management on in its category's folder, so it would undo a move. Left unticked, such downloads stay put and show on the Downloads page.

Labels

What Coldarr does with downloads carrying each of qBittorrent's categories and tags. A download moves only if one of its labels says to, and never if one says to leave it alone. A label with no rule - including one you add in qBittorrent later - is left alone until you give it one. Pick the app that imports a label's downloads, and Coldarr waits until that app has imported each download before moving it.

Seeding rules

How long a download must seed before its trackers are satisfied. Every tracker gets the default unless it has an override; a download that announces to several trackers has to satisfy the strictest. 0 days means forever - never done - which is the default, so nothing is ever treated as done until you say so.

Removing finished seeds

Once a download is done seeding - see Seeding rules - Coldarr can remove it from qBittorrent, from either drive. It never removes a download with no seeding rule met, one Radarr/Sonarr/Lidarr hasn't confirmed importing, one sharing a folder with your library, or one still in use, and never deletes files another download still seeds - that one just leaves qBittorrent. Removals run from the Downloads page or the "Remove Finished Seeds" task.

Mode
Remove deletes downloads from qBittorrent along with their files, which can't be undone. Try Report only first and check the list on the Downloads page. A download on the download drive that's done seeding is then removed instead of being moved to seed storage.

A mistaken rule then costs at most this many downloads and a notification, never the whole drive. The rest wait for the next run.
